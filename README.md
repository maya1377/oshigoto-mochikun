# おしごとモチくん

次々届く仕事を処理し、疲労を管理して定時退勤する短時間の静的ブラウザゲーム。日本語UI、マウス・タッチ操作。

## 遊び方

「出勤する」で開始。仕事カードを選んで行動する。考えている間は時間が進まない。

- 仕事：30分、最大3進捗、疲労+18（疲労70以上は+22）。
- 休憩：30分、疲労-32。
- 先送り：各仕事１回、15分、疲労-8。引き継ぎメモで仕事量+1、受信箱の最後へ移動。今日中の完了は必要。
- 17:00までに６件すべて完了、疲労100未満で勝利。疲労100または定時に未完了で敗北。
- 全件終えたら「定時までひと休みして退勤」。結果から再プレイできる。

## 起動・ビルド

Node.js 22.18以上（検証環境24.21）。

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

`dist/` を静的ホスティングへ配置。外部API、認証、DB、サーバー処理、外部フォント、CDN不要。HTTPで配信する（file://直接起動は対象外）。

## 技術・制作方針

Phaser 3.90 / TypeScript 5.9 / Vite 7.3.7。Game Studioの2D標準ルートを採用。Phaserはオフィスと表情・時計を描画、DOMは日本語の説明と操作を担当。ルールは純粋な状態更新として独立し、描画に勝敗を依存させない。

１プレイ２〜３分の行動選択式。後から届く仕事の時刻を先に示し、初見で予想できる忙しさにした。音声より低負荷の2D表現と操作の分かりやすさを優先。

## Game Studio利用記録

|スキル|担当工程・適用|
|---|---|
|Game Studio|2D標準ルートと制作工程の選択|
|Web Game Foundations|ルールと描画の分離、行動マッピング、保存境界|
|Phaser 2D Game|薄い描画シーン、DOM操作画面、状態から導く表情|
|Game UI Frontend|紙とオフィスの配色、状態の優先順位、画面幅対応、動きを減らす設定|
|Game Playtest|主要行動・勝敗・再プレイ・画面の実ブラウザー検証|

スキルは工程の指針として使用。専用の自動生成・自動公開APIではない。Sprite Pipelineと3D関連は不要なため未使用。画像生成や既存LINEスタンプは使わず、本案件専用のオリジナル仮キャラクターをSVGとPhaserの図形で作成。

## ファイル・素材

- `src/model.ts`：時間・仕事・疲労・勝敗。
- `src/main.ts`：日本語UI、操作、開始・結果画面。
- `src/office.ts`：オフィスとモチくん、表情、時計。
- `src/style.css`：テーマ、レスポンシブUI。
- `public/mochi.svg`：専用キャラクターとアイコン。
- `tests/`：ルールと実ブラウザー試験。
- `verification/REPORT.md`：検証結果。
- `dist/`：ローカル配信用成果物（Gitでは追跡しない）。
