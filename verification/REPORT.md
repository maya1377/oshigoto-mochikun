# おしごとモチくん 検証・制作記録

## 現在の状態
ゲーム本体とローカル検証は完了。GitHub納品を準備中。GitHub Pages公開設定は未変更。

## 制作の流れと判断
1. 指定仕様を読み、Game Studioの2D標準ルートを選択。担当AIは１人、委譲なし。
2. 指定の専用フォルダーを新規作成。指定リポジトリは空であることを確認。他のMyGames内プロジェクトは利用していない。
3. 純粋な状態更新のモデル、Phaserの描画、DOMのUIを分離。
4. 各行動で時間を進める方式にし、思考中にタイマーが減らないようにした。各仕事の到着時刻を事前表示。
5. オリジナルのモチくんとオフィスをSVG／図形で制作。既存の個人素材・スタンプは使っていない。
6. 実装と自動試験、配信用ビルド、実Chromeでのプレイテスト、検証画像の目視を実施。
7. 小さかった行動の効果表示を拡大し、最終ビルドとブラウザー試験を再実施。

## 主要工程で起きた問題
- Windowsの処理文字数制限で最初の一括保存が実行できなかった。ファイル単位の保存へ切り替えた。
- Phaser Graphicsにない曲線メソッドを使った箇所を型チェックが検出。Phaserの曲線を点列に変換して描く方式へ修正。
- 初期のVite 7.3.1と間接依存のesbuildに既知の問題が検出された。Vite 7.3.7と修正版の間接依存へ更新。npm auditは全依存・本番依存とも0件。
- GitHub CLIは利用できなかった。指定リポジトリの参照には接続済みGitHubツール、納品にはGitを使用する方針。
